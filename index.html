Comment lancer le jeu

  1. Dézippez le dossier téléchargé où vous voulez sur votre ordinateur.
  2. Ouvrez le dossier et double-cliquez sur Lancer le jeu.bat.
  3. Le jeu s'ouvre dans votre navigateur. Laissez la petite fenêtre noire ouverte pendant que vous jouez.
