Téléchargement du jeu

Le bouton ci-dessous lit le dossier source du jeu, minifie tout le JavaScript (code compact et illisible) et écrit le paquet dans build/, dans ce même dossier. C'est ce fichier zip que le bouton de téléchargement du site public propose directement aux testeurs : dès que vous publiez une nouvelle version et que vous enregistrez (le champ « Version affichée » se met à jour tout seul après publication), le lien du site pointe sur la nouvelle.

Nécessite Chrome ou Edge (sélection de dossier). On vous demandera de choisir deux dossiers : le dossier source du jeu (ex. « Version en developpement »), puis le dossier de ce site (celui qui contient ce fichier creator.html), pour y enregistrer le résultat dans son sous-dossier build/.
